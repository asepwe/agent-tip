How it works

Type a name like nanako.ai — the contract resolves it on-chain through the Agent ID registry and forwards your BNB to that holder. The tipper must hold an Agent ID, self-tips are rejected, and there is no fee, no owner, and no pause switch. Every tip is confirmed in your own wallet before it is sent.
